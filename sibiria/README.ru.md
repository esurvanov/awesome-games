# Сибирь

**Переживи четыре ночи в эвенкийской тайге, 1993 год, — и построй посёлок вокруг своей избы. Игра-выживание и застройка с видом сверху, прямо в браузере. Без установки и без сборки.**

Январь 1993-го. Вертолёт Ми-8, борт 24713, упал на излучине реки в Эвенкии. Ты — Лёша, радист. Рация разбита, экипажа нет, до людей — дни пути. Найди старое охотничье зимовье, растопи печь, встреться со стариком-эвенком Уркачаном, вытащи из хвоста вертолёта раненую геологиню Веру и заставь рацию заговорить, пока тайга не взяла своё.

## ✨ Возможности

| | | |
|---|---|---|
| 📖 **Семь глав** — Обломки, Уркачан, Стая, Сигнал, дальше Промысел, Зимовка или Экспедиция; записки, печатающиеся диалоги, сухой юмор | 🔥 **Настоящий холод** — тепло, голод, обморожение, пурга; безопасно только у огня | 🐺 **Стая охотится** — разведчик, сжимающееся кольцо, бросок; волки боятся огня и факела |
| 🏚 **Изба растёт** — щели, дверь, верстак, заслонка; спи, чтобы сохраниться | 🏘 **Свой посёлок** — нанимай людей, строй 8 видов зданий, проходи 4 эпохи, торгуй за рубли | 🐻 **Шатун** — громит коптильню, ворует еду, выламывает дверь |
| 🎣 **Рыбалка на реакцию** — хариус, таймень, налим; у каждой рыбы свой вес | 🧭 **Управление как в RTS** — рамка, приказы правой кнопкой, группы, набат, масштаб | 🎧 **Весь звук синтезируется** — ветер, вой, шаги, музыка, которая следует за опасностью |
| 🏆 **Пять концовок** — все домой, один, тайга приняла, новый посёлок, экспедиция на «Кербо-2» | 📱 **Работает на телефоне** — джойстик, режим приказов, щипок, автонастройка качества | 💾 **3 ячейки сохранений + автосохранение** — спи в избе, чтобы закрепить прогресс |

## 🗺 Большой мир

Около 11 × 11 км тайги вокруг места крушения, восемь зон, и каждая меняет правило игры: **наледь** мочит унты, на **гари** костёр горит дольше, на **курумнике** легко подвернуть ногу, на ветреном **гольце** далеко видно, есть старая **буровая**, **метеостанция «Кербо-2»**, **зимник** с факторией и **стойбище** эвенков. Там живут одиннадцать человек — метеоролог, вахтовики, шаманка, старовер, почтальон и другие, — у них 15 заданий. Срубленный лес отрастает, в поле можно оставить тайник (`T`), по тайге ходишь на лыжах, ездишь на оленьей упряжке или на починенном «Буране», маршруты прокладываешь по большой карте-схеме (`M`).

## 🎮 Управление

| | Клавиатура и мышь | Телефон |
|---|---|---|
| Ходьба | `W` `A` `S` `D` | джойстик |
| Действие (рубить, рыбачить, читать, говорить) | `E` | кнопка 🪓 |
| Огонь · еда · ловушка | `F` · `Q` · `R` | круглые кнопки |
| Мастерская · стройка | `C` · `B` | кнопки |
| Нюх: найти добычу и находки | `V` | кнопка |
| Выбрать людей | рамка, `Shift` добавляет, двойной клик — все такого же типа | тап или кнопка режима приказов |
| Приказ | правая кнопка по дереву, льду, обломкам, стройке, врагу или земле | тап при выбранных людях |
| Набат / отбой | `H` | кнопка |
| Камера | колесо — масштаб, средняя кнопка или край экрана — сдвиг, `0` — к герою | щипок, перетаскивание |
| Пауза | `Esc` | кнопка |

## 🚀 Запуск

Игра — статические файлы: без зависимостей и без сборки.

```bash
cd sibiria
python3 -m http.server        # затем откройте http://localhost:8000
```

Можно просто открыть `index.html`.

## 🧪 Тесты

```bash
cd sibiria/tests && npm i && node run-all.js
```

Двенадцать проверок в настоящем браузере: дымовые прогоны, настоящая мышь и касания, сохранение и загрузка, отсутствие наложений интерфейса на четырёх размерах экрана, попиксельное сравнение 16 сцен и три прохождения ботом.

## 🛠 Устройство

| Файл | Что делает |
|---|---|
| `js/data.js` | мир, предметы, рецепты, здания, эпохи, главы, диалоги, записки |
| `js/game.js` | состояние, выживание, директор угроз, волки, шатун, сюжет, сохранения |
| `js/colony.js` | посёлок: работники, стройка, эпохи, улучшения, рынок, набат |
| `js/input.js` | единая модель ввода: состояния, курсоры, зоны попадания, камера, приказы |
| `js/gfx.js` · `js/art-*.js` | рендер, свет и тени; суставные люди, звери, постройки, эффекты |
| `js/ui.js` · `js/icons.js` | интерфейс на единой дизайн-системе, 99 иконок |
| `js/audio.js` · `js/finale.js` | синтезированный звук и музыка; финальные сцены |

Исследования, стоящие за последней большой переработкой (аудиты, гид по стилю, спецификации), лежат в [docs/design](docs/design/).
