# SPEC-art · Графика «Сибири 2.0»

**Фаза 3 · трек «Графика».** Сводка квантов [C1](C1.md) · [C2](C2.md) · [C3](C3.md) · [C4](C4.md) · [C5](C5.md) · [C6](C6.md) · [C7](C7.md) · [C8](C8.md) · [C9](C9.md) · [D1](D1.md) · [E1](E1.md).
**Итог аудита.** Скорость в норме (кадр 0.9–1.9 мс на M1, 7.8 мс на слабом CPU). Картинка расходится сама с собой: слои после карты света не знают о ночи, у теней два источника, кэши не знают о зуме, 26 элементов нарисованы в старом стиле, финал — в третьем.

```
3 замысла                       3 правила-инварианта (закрывают класс ошибок целиком)
«один свет на сцену»     ──►  всё, что рисуется после карты света, × ambient (кроме огня/окон/глаз)
«одно солнце»            ──►  направление тени задаёт только drawShadows; в спрайте — контактная
«резко на любом зуме»    ──►  масштаб любого кэша = rdpr × ступень зума
```
