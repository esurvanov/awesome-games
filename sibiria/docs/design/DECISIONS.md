# Решения по «Сибирь 2.0» (25.09.2026)

| Развилка | Решение |
|---|---|
| Масштаб мира | Сразу ×9 (≈10 800 × 10 800), все 8 зон и транспорт одним заходом |
| Сюжет | Посёлок открывает дальние промысловые участки; при провале вертолёта — поход к метеостанции. Текущие 4 главы сохраняются |
| Облик интерфейса | «Жесть и краска» (HUD, панели) + «бумага» для документов (меню, записки, бортжурнал, итоговый акт) |
| Старые сохранения | Обнуляются с понятным сообщением; старый генератор не храним |
| Камера | Возврат к герою от первого нажатия WASD; инерция после перетаскивания — для мыши и пальца |
| Слабые иконки (7) | Собираются из готовых силуэтов game-icons/Lucide |
| Герой | WASD + героя можно выделить и отправить ПКМ (SPEC-input, B5) |

Спецификации: SPEC-world.md, SPEC-input.md, SPEC-art.md, SPEC-ui.md.
