## 3. 🌐 Общие правила экосистемы

### R1 🌬 Единый ветер

`Wind.at(x, y)` → `{ ms, gust 0..1, dx, dy }`. Один модуль, шаг в `Interact.tick` (или свой `js/ecosys.js`), рендер читает через `ENV`.

```
ms = base(погода, час) × (0.35 + 0.65 · gust(x,y,t)) × местность(x,y)
gust = нынешний gustAt (шум, бегущий по +x со скоростью 110 px/с) — переносится из gfx в логику
```

| Погода | м/с | Бофорт | `ENV.wind` (как сейчас для елей) |
|---|---|---|---|
| 🌙 тихий мороз (вечер → 2–3 ч после восхода) | 0–1.5 | 0–1 | 0.3 |
| ☀️ обычный день | 2–5 | 2–3 | 1 |
| 🌬 ветреный день 🆕 (~25 % дней) | 6–10 | 4–5 | 2 |
| 🌪 пурга | 15–20 | 7–8 | 4 |

| Местность | × |
|---|---|
| 🌲 под пологом леса | 0.5 |
| 🟫 марь, 🧊 река, 🏔 голец | 1.2 · 1.2 · 1.6 |

**Переводы:** снос частиц = `ms × 16 px/с` (даёт нынешние 25 в штиль и 294 в пургу) · изгиб елей = `ms / 4.5` · снос героя на гольце = нынешние 28 px/с при 8 м/с.
**Удаляется:** `storm ? 80 : 12` в спавнах дыма, свой порыв в audio, `sin(t·3)` вымпела.

### R3 ❄️ Единый снег-накопитель

| Что | Правило |
|---|---|
| 🎩 Шапка на вещи `cap 0..1` | + снегопад (0 → 1 за ~1 сутки снегопада = 480 с); − сдув при ms ≥ 8: `(ms−8)/10` в с; = 0 при ударе/толчке → ком падает (`snowPuff` / `branchSnow`) |
| 🏔 Наддув (подветренный) | главный нанос **за** вещью по ветру: длина до 6 h (игровой потолок 3 h), глубина до 1.2 h; наветренный — ~0.5 h, тонкий, до 15 h; у самой стенки — выдутая ямка |
| 📶 Уровни | наддув растёт ступенями 0–3 (перенос ≥ 4 м/с × время); смена ступени = перепечь один кусок земли (есть очередь `bakeRun`, gfx.js:840) |
| 🌲 Кухта | ель держит 30–80 % снегопада, береза меньше; ветер ≥ 8 сбрасывает; в тихий мороз держится; срыв → лапа распрямляется с отскоком 0.3–0.6 с (через `t.shake`) |
| 👣 Следы | жизнь следа × по ветру: < 4 м/с ×4 · 4–8 ×1 · ≥ 8 ×0.5 · пурга ×0.25 (как сейчас) |
| 💾 Сейв | не пишется (как `SKIP`, savegame.js:12); при загрузке уровни восстанавливаются от дня и погоды |
