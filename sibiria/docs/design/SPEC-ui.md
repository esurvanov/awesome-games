**Эталон вида:** [mock/sib-ds.css](mock/sib-ds.css) (токены и классы — переносить как есть), [mock/D4-hud.html](mock/D4-hud.html) (HUD, панель, меню), [mock/D5-screens.html](mock/D5-screens.html) (экраны), [mock/D3-components.html](mock/D3-components.html) (состояния), спрайт [mock/sprite.js](mock/sprite.js) + [mock/icons-map.json](mock/icons-map.json).

## 1. 🔩 Облик

| Решение | Где | Почему |
|---|---|---|
| ✅ **«Жесть и краска»** (эмаль кабины Ми-8, трафарет, заклёпки, янтарные лампы) — основа | HUD, панели, кнопки, тосты, пауза, сохранения, гибель, титры, канвас-плашки | контраст на снегу **10.1 : 1** (бумага 1.1 : 1); ночью светятся только лампы и цифры — не спорит с огнём (C2); Frostpunk подтверждает металл для постоянных приборов |

| ❌ Полный бумажный HUD | — | днём растворяется в снегу, ночью 5–7 ярких листов слепят (10.5 : 1) |
| ⚠️ Ночью | металл | обязательна светлая кромка `--c7` (без неё 1.1 : 1, как у нынешнего стекла) |

### 4.2 Как встраивать

| # | Правило |
|---|---|
| 1 | Файл **`js/icons.js`**: вставляет в начало `<body>` скрытый `<svg>` с `<symbol id="i-…" viewBox="0 0 512 512">` (Lucide — `0 0 24 24`, `stroke`) и экспортирует `ICON_D = { wood:'M…', … }`. `build.py` уже вклеивает `js/*.js` в `dist` — работает с `file://` |
| 2 | DOM: `ic(id, size)` → `<svg class="ic s|l|xl"><use href="#i-id"/></svg>`; цвет = `currentColor`, состояния красятся токеном, без `filter: grayscale` |
| 3 | Канвас: `Path2D(ICON_D[id])` + `ctx.scale(px/512)`; один источник для DOM и холста; экранный размер ≥ 14 px |
| 4 | Подготовка GI: удалить фон `M0 0h512v512H0z` и `fill="#fff"`; округлять до 0.1 **только разборщиком пути** (слитные флаги дуг) |
| 5 | Lucide не мельче 16 px и только в системной зоне (углы, меню, пауза); в шкалах и плитках — только силуэты GI |
| 6 | Вес: +92 КБ сырой / **33 КБ gzip** (+16% к `dist`) |
| 7 | Тёмным иконкам на тёмном — лунка `.ri` / `.tile`, как в строках |

## 5. 📐 Масштаб: 4 системы → 1

| Было (D6) | Станет |
|---|---|
| ① `zoom: var(--ui)` на 10 блоках · ② экраны без масштаба (clamp у h1) · ③ канвас-оверлеи через `dpr × zoom` камеры · ④ финал `min(W/1000, H/640)` | **один множитель `--ui`** на всех слоях |

**Формула** (ставит `ui.js` при `resize` и смене настройки, пишет в `--ui` и `UI.scale`):

```
auto = W < 700 ? clamp(0.80, W / 400, 1.00)          // телефон
               : clamp(0.85, min(W / 1280, H / 800), 1.50)
ui   = clamp(0.75, auto × set, 1.80),  set ∈ { S 0.85 · M 1 · L 1.2 }
```

| Размер | auto | ui при S / M / L |
|---|---|---|
| 📱 360×780 | 0.90 | 0.77 / 0.90 / 1.08 |
| 💻 1280×800 | 1.00 | 0.85 / 1.00 / 1.20 |
| 🖥 1920×1080 | 1.35 | 1.15 / 1.35 / 1.62 |
| 🖥 2560×1440 | 1.50 | 1.28 / 1.50 / 1.80 |

| Слой | Как слушает `ui` |
|---|---|
| HUD, приказы, диалог, панель, тосты, подсказки, тач, записка | `zoom: var(--ui)` (как сейчас) |
| Меню, пауза, сохранения, итог, титр главы/эпохи, баннер зоны, стрелки ➤, джойстик | **добавить** в то же правило `zoom` |
| Компас, полоса рыбалки, «Клюёт!», метки нюха, рамка выделения | `setTransform(rdpr × ui)` — **не** `dpr × zoom` |
| Подписи в мире, 💬 ❗, «2/4», кольцо действия | остаются от зума камеры (часть мира), минимум 11 px на экране |
| Финал | `U = ui` вместо `min(W/1000, H/640)` |
| Мини-карта | буфер `128 × rdpr`, значки ≥ 14 px |
