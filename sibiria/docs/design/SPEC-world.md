## 3. ⚖️ Открытые развилки

### 3.1 Масштаб ×4 или ×9

| Показатель | ×4 (7200²) | ×9 (10 800²) | Квант |
|---|---|---|---|
| Экранов 1280×800 | 51 | 114 | A1 |
| Деревьев (со стенами) | 3 936 | 8 364 | A2 |
| Генерация | 10,3 мс | 30,7 мс | A2 |
| Обновление, ночь, CPU ×4 | ~1,2 мс (оценка) | 2,48 / 4,1 мс p95 | A2 |
| Кадр посёлка, CPU ×4 | 9,41 мс (+21 %) | ~12 мс (оценка, до отсечения) | C8 |
| Перепечка снега, CPU ×4 | — | 21,7 мс 🔴 | A2 |
| Сейв полный / дельта | 351 КБ / ~35 КБ (оценка) | 735 КБ / 76 КБ | A10 |
| 4 ячейки, доля лимита (полный) | 27 % | 57 % | A10 |
| Сетка пути 16 px | 3,4 МБ | 7,7 МБ | A2 |
| Диагональ пешком по целине | ~100 с | 150–200 с | A7 |
| Нужен транспорт | 🟡 слабо | 🟢 ровно на этом размере | A7 |
| 8 зон по кольцу, шаг | ~2 200 px 🟡 (ниже коридора) | 2 500–3 500 px 🟢 | расчёт по A7 |

**За ×9:** транспорт и быстрый переход осмысленны; 8 зон помещаются в коридор A7. **Против ×9:** 114 экранов контента, снег и посёлок требуют правок до запуска, риск пустоты (нижняя треть мира уже пустая, A1).

**Рекомендация:** архитектура сразу под ×9 (всё от `WORLD.scale`), выпуск по шагам: **×4 с 4 зонами → замер → ×9 с 8 зонами** (порядок E-sum). Масштаб растёт вместе с числом зон.
