# Данные посадочной страницы «Березовки»

`page.json` — текст страницы игры (название, описание, особенности, управление, факты, FAQ, скриншоты) в формате записи GamePage сайта urvanov.com.
Сайт забирает файл отсюда при выкладке; правьте факты здесь, рядом с кодом игры.
Поле `file` в `shots` — путь относительно папки игры (`docs/screenshots/...`).
