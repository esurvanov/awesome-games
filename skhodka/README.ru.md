# Сходка

[🇬🇧 English](README.md) · 🇷🇺 **Русский** · **[▶ Играть](https://www.urvanov.com/skhodka/)**

Субботний вечер в баре SushiGO (Батуми), 19:00 → 01:00, ~18 минут. Ты — участник IT-чата: знакомься, дружись,
своди людей между собой. Люди — собирательные образы, имена вымышлены.

![зал в пик](docs/screenshots/game-05-hall-peak-2130.jpg)
![разговор](docs/screenshots/game-06-talk.jpg)

## Запуск

Открыть `index.html` двойным щелчком. Сервер, сборка и библиотеки не нужны (three.js лежит рядом).

`?seed=42` в адресе — повторить тот же вечер. Статический сервер: `node tests/serve.js` → http://127.0.0.1:8080/
(для тестов: `cd tests && npm install` один раз).

## Устройство

```
index.html         холст + слой интерфейса; части — обычные <script> с реестром L (js/l.js), список — js/manifest.js
js/core.js         RNG с сидом, шина событий, фиксированный шаг (Loop), настройки
js/content/        ДАННЫЕ: план зала, роли, склады, настроения, архетипы, чудики, темы, карты, реплики, события, чат, числа
js/sim/            вечер без DOM и THREE: навигация, толпа, поведение, разговор, режиссёр событий, очки, мир
js/render/         3D (three r158): зал, свет и эффекты, камера, качество; люди — один SkinnedMesh на человека
js/ui/             HUD, разговор, карточка человека, телефон, экраны (заставка, анкета, чат, итог), иконки
js/main.js         сборка: экраны → мир → один rAF-цикл; мир → люди в 3D, час → свет, события → эффекты,
                   ввод по залу, камера на разговор, общее фото для итога; window.SKHODKA — для тестов
docs/              plan.md — договор частей, scenario.md — вечер по часам, screenshots/
tests/             Node + Playwright
```

Все числа содержания — в одной шкале 0..1 (силы, симпатия, пороги). Схемы — в шапках файлов `js/content/*.js`.

## Тесты

```sh
cd tests
node content.js      # содержание: схемы, ссылки, шкалы 0..1, иконки в спрайте
node sim.js          # вечер в Node: кривая толпы, разговоры, пары, фото, звания; хороший и плохой игрок
node smoke.js        # браузер (сервер и file://): анкета → зал, пауза, клик → разговор → ответ, заказ, ходьба, весь вечер → итог с фото
node perf.js [gpu|soft|all]   # CPU ×4, зал в пик: ноутбук и телефон; soft — без видеокарты
node balance.js [сидов] [--browser]   # баланс: боты в темпе человека (активный, средний, осторожный, наугад)
node play.js [seed] [390x844]   # сыграть вечер мышью как игрок, снимки в tests/play/
node shots.js        # снимки игры → docs/screenshots/game-*.png
node scene-shots.js · node people-shots.js · node ui-shots.js   # стенды частей (dev/*.html)
```
