## Правила

```
подойти → 👋 поздоровался → 💬 поговорили → ✨ общая тема → 📲 контакт → 🤝 договорились
  видел         (карта)        симпатия .28     совпала тема     .52 + доверие     .72 + нужда↔предложение
```

| | Ресурс | Тратится | Восполняется |
|---|---|---|---|
| ⏰ | Время | часы идут и в разговоре | — люди приходят и уходят |
| 🔋 | Силы (0–1) | карты, «bad», стробоскоп | 🍺 пиво · 🍣 роллы · 🥟 хачапури · ☕ кофе · 🚶 улица |
| 📱 | Телефон | — | ответил «иду встречать» → у двери быстрое знакомство |

**Разговор** — рука из 3–4 карт (иконка + 2–4 слова). Реакция:

| Карта попала в… | Реакция | Симпатия |
|---|---|---|
| ✅ любимый стиль склада / тему / настроение | good | +.13 |
| ➖ ни то ни сё | meh | +.03 |
| ❌ стиль, который бесит · больная тема | bad | −.12 (3 подряд — уходит) |

**Стили карт:** ❓ спросить · 👤 рассказать · 👂 слушать · 😂 шутить · 📊 факты · 🤚 помочь · 🔥 спорить · ⭐ мечтать · 👍 хвалить · ⏸️ молчать · 🛋️ звать · 🍺 угостить.

**Человек** = 💼 роль + 🧠 склад + 🌤 настроение + 🚶 архетип (+ редко 🧩 чудик).
