## 7. 🤝 Взаимодействие объектов

**Сейчас (честно):**

| Кто с кем | Сейчас | Качество |
|---|---|---|
| Пилот ↔ снег | продавливает телом | ✅ |
| Пилот ↔ валун | опирается руками | ✅ валуны / 🟡 часть камней |
| Пилот ↔ камень как стена | одна грубая «скорлупа» — упор в воздух | 🔴 |
| Пилот ↔ ёлки | задел — сыплется снег; ствол-цилиндр | 🟡 |
| Пилот ↔ ящики/бочки | толкает | 🟡 |
| Пилот ↔ палатки/постройки | просто стена | 🔴 |
| Тело пилота | только анимации, на толчки не реагирует | 🔴 |
| Звери ↔ снег | следы под копытами | ✅ |
| Звери ↔ предметы | нет | 🔴 |
| Предмет ↔ предмет | нет | 🔴 |

**Почему:** каждое взаимодействие — отдельный частный случай пары; общего слоя нет; формы столкновений грубые; тело не физическое.

**Стандарт индустрии (исследовано):** у предмета «паспорт взаимодействия» — готовые точки (куда рука, где встать, какой рукой);
у игрока роль «взаимодействую», между ними посредник (как Unity XR Interaction Toolkit, Unreal grab points, Uncharted — маршруты согласованы с анимацией).

**Для браузера:**

| Часть | Как |
|---|---|
| Точки на моделях | пустые метки в модели / данные glTF «extras» → three.js кладёт их в userData; либо файл-список точек рядом с моделью |
| Неразмеченные сканы камней | луч по настоящей поверхности через three-mesh-bvh (сделано для рук) |
| Цена (замерено, с исправлением первой оценки) | луч 0,007 мс (0,043 мс при процессоре ×6 медленнее); удержание позы 2 руки × 60 кадров = до 0,09 мс/кадр; разовая подготовка всего 168 мс (до 747 мс на ×6) → готовить только касаемое, без гор, по частям во время загрузки; память 4,3 МБ |

**Паспорт точек пока не сделан** — агент успел только первый шаг (рука в нарисованную поверхность).

## 11. 🌲 Реалистичные и лёгкие модели

**Рецепт для любого предмета:** подробный исходник → несколько тысяч граней → мелкий рельеф запекается в текстуру → текстура до 1024 →
2–3 уровня детализации, вдали картинка → лимит на предмет (грани, текстуры, 1 материал) проверяется автоматически.

| Источник | Плюсы | Минусы | Для чего |
|---|---|---|---|
| 🆓 Poly Haven (без ограничений) | настоящие сканы | мало выбора | камни |
| 💳 Fab / Megascans (с 2025 в основном платно) | лучшее качество | деньги, лицензия | обломок, станция |
| 📱 Сканы телефоном (Scaniverse, конвейер готов, tools/scan/SHOTLIST.md) | реальные вещи, бесплатно | ёлки и огонь не сканируются | камни, пни, брёвна, палатка |
| 🤖 Генерация (Hunyuan3D и др.) | быстро по картинке | неаккуратные грани/текстуры; лицензия не действует в ЕС/UK | мелочи |
| 🧮 Кодом | ничего не весит | ручная настройка | ёлки (объём кроны), огонь (пламя по кадрам) |

записываем рецепт (источник, грани, текстуры, настройки, цена на Air) → тиражируем. Три принятых предмета = общее мерило.

## 14. 🔁 Почему проблемы повторялись (структура)

| Где терялась информация | Лечение |
|---|---|
| Агенты проверяли **свою** правку отдельно, сумму никто | правила на **собранную** игру в каждой общей проверке |
| Сравнение «не хуже прошлой версии» из тестовых точек, а не с твоей точки обзора | снимки с твоей камеры, на Retina, в движении, рядом с твоим фото |

| Шумная общая машина | повторы, сравнение внутри одной вкладки |

**Правила, которые закрываются формулой навсегда:** лимит текстурных слотов; размеры по таблице; зазор форма ↔ видимая поверхность ≤ 3 см;
яркость материалов 50–240; скорость на профиле Air. **Не закрывается списком:** «ощущается настоящим» → пробник и твоё «да».
