## 🧩 Что сделано

| Узел | Решение |
|---|---|
| 🦌 ориентация | модель смотрит в +Z = направление бега: убран разворот π (игра + interaction) |
| 🛷 после езды | `rotation.set(0, face, 0)`: кватернион саней (эйлер с флипом) больше не остаётся |
| 🏃 походка | walk ↔ jog ↔ sprint — одна фаза, веса по скорости, старт с фазы «нога как в idle», разгон ≤ 20 м/с², тело смотрит по скорости |
| 🦊 🗿 🦌 | та же фазовая походка для лисы и голема; скорость ≤ того, что шагает клип (лиса 7.2, олень 4.0 м/с), голем назад — клип назад |
| 🧗 подъём | уступ 0.8–1.8 м на любом STATIC (камни, «solid», обломок DC-3), захват из прыжка; тело по кривой клипа ClimbUp_1m (руки → нога), левая нога фиксируется IK на верху |
| 👣 опора | terrain: CPU-копия видимого снега (сглаженный рельеф + рыхлый снег + микрорельеф − продавленность) + журнал штампов; ботинок/копыто встаёт на видимую поверхность и продавливает подушку + отпечаток |
| 🎥 камера | кроны деревьев измерены из геометрии → штанга мягко укорачивается; стволы режут сразу; смена плеча при закрытом виде; рыскание — только игрока |
| ⬛ NaN | копия сцены в пост-цепочке заменяет NaN/Inf соседями (bloom больше не размазывает); зерно гаснет в чёрном, уровень чёрного 1/255 |
| 👻 невидимый пилот | `shellInside` (structures) дублировал индексы поверх interleaved-буфера → драйвер отбрасывал весь пилот; теперь атрибуты раскладываются |

## ⚠️ Осталось

| Пункт | Почему |
|---|---|
| 🦊 лиса 0.158 м/шаг | в клипе Run передние лапы метут в ~3 раза медленнее задних: на любой скорости одна пара скользит (ассет) |
| 🗿 голем таз 16 м/с | клипы атак 8-метрового голема; замедлены, но при повторе атак всё ещё > 10 |
| 🎥 `wf_mist` у линзы | прозрачный лист тумана, гаснет в 3 м от камеры — ложное срабатывание проверки «ближняя плоскость»; нужен тег intentional в worldfill/QA |
| 👣 глубокий сугроб −0.15 м, камп −0.06 | промах модели размытия штампа на GPU; в отдельных прогонах те же точки проходят |
