# 📸 Шот-лист сканов — «Эхо Разлома»

Сканируем в **Scaniverse** (бесплатно, всё считается на телефоне). Потом одна команда:

```
node tools/scan/import.mjs ~/Downloads/scans
```

## ⚙️ Общие правила

| | Правило |
|---|---|
| ☁️ | **Пасмурно** или ровная тень. Солнце и резкие тени запекаются в текстуру |
| 🔁 | **3 круга**: на уровне пояса, сверху под 45°, снизу у земли |
| 📏 | **0.5–1.5 м** до объекта, объект занимает ½ кадра |
| 🐢 | Медленно, без рывков; 60–90 с на объект |
| 🚫 | Нет бликов, мокрого, стекла, движущихся веток, людей в кадре |
| 🟫 | 20–30 см земли вокруг — ок, пайплайн сам срежет |
| 🏷️ | **Имя файла = роль**: `boulder_…`, `stump_…`, `ice_…`, `brick_…`, `crate_…`, `tire_…`, `snow_…` |
| 📤 | Mesh → **GLB** (или OBJ) · Splat → **SPZ** (или PLY) |

**Режим:** 🧱 **Mesh** — всё, что будет в игре предметом (коллизия, LOD). ✨ **Splat** — только для пресета *ultra*: фото-сцена без коллизии.
