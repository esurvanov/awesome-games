# awesome-games

- [age-of-empires](age-of-empires/) — «Хроники Королевств»: историческая стратегия в реальном времени в духе Age of Empires II (Python, pygame-ce). Запуск: `Играть.command` (macOS) или `python3 -m venv .venv && .venv/bin/pip install pygame-ce numpy && .venv/bin/python main.py`. Графика и звук — из открытых проектов 0 A.D. и Millennium A.D.
