# Северный Разлом

**Лети на маленьком корабле по бесконечному ледяному каньону под северным сиянием — 3D-аркада в одном файле, прямо в браузере.**

Каньон не кончается. Собирай кристальные осколки, копи из них энергию и пробивай ледяные стены. Облетай препятствия, проходи над ними и под ними, держи множитель — и смотри, как далеко улетишь, пока три удара не собьют корабль.

## ✨ Что внутри

| | | |
|---|---|---|
| ♾ **Бесконечный каньон** — строится на лету, каждый раз новый | 💎 **Осколки → энергия → лёд вдребезги** — прорыв сквозь стены | ✖️ **Множитель ×2 … ×8** — за облёты, пролёты над и под |
| 🛡 **3 удара** — и забег окончен | 🌌 **Сияние, звёзды, светящиеся кристаллы** — всё нарисовано кодом, без картинок | 📱 **Сенсорное управление** — на телефоне появляется кнопка прорыва |

## 🎮 Управление

| | |
|---|---|
| `W A S D` / стрелки | руль |
| `Space` / `Shift` | прорыв сквозь лёд |
| `Enter` | старт |

## 🚀 Запустить у себя

Откройте **[esurvanov.github.io/awesome-games/severny-razlom](https://esurvanov.github.io/awesome-games/severny-razlom/)** — или двойной щелчок по `index.html`. Это один файл: three.js и шрифты подгружаются из сети.

Это первая игра в мире [Эха Разлома](../ekho-razloma/README.ru.md) — тот же остров, только с воздуха.
