# Архитектура «Северного Разлома»

Источник правды для статьи в блоге urvanov.com: сайт забирает отсюда текст и схемы при каждой выкладке.

| Файл | Что это |
|---|---|
| `architecture.ru.md`, `architecture.md` | Статья на русском и английском (обычный markdown, схемы подключены картинками) |
| `diagrams/ru/*.svg`, `diagrams/en/*.svg` | Схемы C4 и sequence: каждая самодостаточна, светлая и тёмная тема подхватываются сами |
| `post.json` | Данные для блога: адрес, дата, описания, оглавление |
| `_src/` | Генератор схем и текстов: `python3 _src/build.py .` пересобирает всё выше |

Правка текста: меняйте `_src/build.py` и запускайте его (файлы выше генерируются, правка вручную перезапишется).
