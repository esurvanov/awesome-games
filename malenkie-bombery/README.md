# 💣 Little Bombers

An arcade game in one file: drop bombs, blow up crates and enemies, find the exit hidden under a crate.

| | |
|---|---|
| 🗺 **50 levels** · 10 worlds (meadow, dunes, ice, lava, swamp, space, jungle, ruins, neon, sunset) · 🏆 **18 achievements** | ⭐ **up to 3 stars** for speed |
| 👾 **3 enemies** · slime, bat (charges in a line), ghost (passes crates) | 🎁 **power-ups** · +bomb, +fire, +speed, carry over to the next level |
| 🧱 **editor** · your own levels, test, share by code | 💾 **saving** · progress, best times and your levels in the browser |

## 🎮 Controls

| | |
|---|---|
| `← ↑ → ↓` / `WASD` | move |
| `Space` / `X` | drop a bomb |
| `Esc` / `P` | pause |
| `R` | restart |

On a phone: a joystick and a bomb button.

## 🚀 Run

Double-click `index.html`. No build and no libraries: Canvas 2D, sound through Web Audio. Everything is stored in `localStorage` under the key `malenkie-bombery.v1`.
