# 💣 Маленькие бомберы

Аркада в одном файле: ставь бомбы, взрывай ящики и врагов, ищи выход под ящиками.

| | |
|---|---|
| 🗺 **50 уровней** · 10 миров (луг, дюны, лёд, лава, болото, космос, джунгли, руины, неон, закат) · 🏆 **18 наград** | ⭐ **до 3 звёзд** за скорость |
| 👾 **3 врага** · слизень, летун (гонится по прямой), призрак (сквозь ящики) | 🎁 **бонусы** · +бомба, +огонь, +скорость, переходят на следующий уровень |
| 🧱 **редактор** · свои уровни, проверка, код для обмена | 💾 **сохранение** · прогресс, рекорды и свои уровни в браузере |

## 🎮 Управление

| | |
|---|---|
| `← ↑ → ↓` / `WASD` | ход |
| `Space` / `X` | бомба |
| `Esc` / `P` | пауза |
| `R` | заново |
| `1`…`=` | инструмент в редакторе |

На телефоне — джойстик и кнопка бомбы.

## 🚀 Запуск

Двойной щелчок по `index.html`. Без сборки и библиотек: Canvas 2D, звук через Web Audio.

Всё хранится в `localStorage` под ключом `malenkie-bombery.v1`.
