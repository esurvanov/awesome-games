# Посадочная страница игры

Содержимое страницы «Хроники Королевств» (название, описание, возможности, управление, факты, FAQ, скриншоты) в формате `page.json`: те же поля, что у записи игры на сайте.
Читает сайт urvanov.com при выкладке; пути в `shots[].file` считаются от папки игры, факты сверяются с `README.md` и кодом.
