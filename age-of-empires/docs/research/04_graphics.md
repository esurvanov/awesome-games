## 🔀 Как чинится

| 🔁 Перерендер / параметры (tools/render3d, build_*) | 🧱 Новая система |
|---|---|
| масштаб юнитов (S_INF/S_CAV) ↓ ×0.45–0.6 | ⛰️ высоты: карта высот, склоны, свет склонов |
| FILL зданий → ≈1.0–1.05 основания | 🪨 утёсы как объекты |
| SUN зеркально (тени влево-вниз) | 👤 силуэты юнитов сквозь здания/деревья |
| кадры: 8 → 20–30 на цикл | 🌊 мелководье как тип клетки + анимированные волны |
| направления 8 → 16 | 🧩 смешение клеток масками (blendomatic-подобно) |
| яркость/тепло: Look.sun/amb/saturation | 🌲 прозрачность/контур деревьев над юнитами |
| тень стрелы, 32 угла стрелы | 🔥 3 стадии огня (75/50/25) — мелкая доработка |
| жилы: спрайты по остатку (66/33 %) | 🗂️ 30+ типов земли (визуально) |

Константы (без рендера): цвета игроков и порядок, время трупов/развалин, цвет полосок здоровья.
