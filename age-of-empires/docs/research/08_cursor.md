# 🖱 08 · Курсор: ориентация, точка прицела, размер, выбор состояния

Жалоба: «курсор странно перевёрнут и плохо указывает в точку». Метод: **1 квант = 1 состояние курсора × 1 свойство**.
Свойства: 🔄 ориентация · 🎯 прицел (объявленная точка vs визуальное остриё) · 📏 размер на экране · 🧭 выбор состояния · 🎨 вид vs DE.
Вердикт: ✅ как в DE · ⚠️ отличие, терпимо · ❌ ломает ощущение / указывает мимо · 🚫 состояния нет.

```
assets/ui/cursors/*.png ──cursor_static──► static.json + preview.png      (маска, остриё, зеркала vs 0 A.D.)
игра без окна ──cursor_hover_probe──► hover.json                          (наведение при zoom 1.0/0.7/1.4, высота)
настоящее окно ──cursor_nscursor_probe──► nscursor.json                   (что macOS получает от SDL: пункты, hotSpot, Retina ×2)
эталон DE (shots/ref/cursors, локально) + 0 A.D. ──cursor_sheet──► shots/research_cursor/sheet.png
```

## 🔬 Замеры

**Маска (static.json).** Стрелка: рамка (0,1)–(26,31), остриё (0,31); мини-стрелка в `de_*`: остриё (0,16), предмет в (8..31, 8..31).
Меч: рамка 23×23 в файле 64×64 → 11×11 после `smoothscale` до 32; прицел `int(1×0.5)` = (0,0).

**Настоящее окно (nscursor.json, M1 Pro, окно 1280×800 `SCALED`).** `backingScaleFactor` 2.0; окно 1280×800 пт = 2560×1600 физ. px;
`renderer_logical` 1280×800. Курсор «стрелка»: NSImage 32×32 **пт**, одно представление 32×32 px, hotSpot (1,1) пт → **64×64 физ. px**,
масштабирует macOS (мыло). Так делает SDL2: `Cocoa_CreateImage` ставит `NSMakeSize(surface->w, surface->h)` и один `NSBitmapImageRep`;
`Cocoa_CreateCursor` → `initWithImage:hotSpot:` с целыми пунктами. Подсказок SDL для масштаба курсора нет; pygame-ce 2.5.8 / SDL 2.32.10
(`pygame.cursors.Cursor` в документации — только «hotspot внутри surface»). Retina-представление (2×) через SDL2 передать нельзя.

**Снимок экрана с курсором** (`tools/research/cursor_real_window.py`, `screencapture -C`) — в этой сессии терминалу не дано разрешение
«Запись экрана»: снимок содержит только обои, окно и курсор в нём не видны (`shots/research_cursor/real/_base.png`). Скрипт готов:
выдать разрешение Terminal → запустить → получит физический размер и промах остриё по каждому курсору.

**Наведение (hover.json).** Житель выбран, туман снят, zoom 1.0 / 0.7 / 1.4: дерево, золото, камень, ягоды, центр (сдать), стройка,
животное, враг-юнит, враг-здание — **27/27 состояний верны**, дерево на высоте 111 px — верно во всех трёх масштабах. Точка прицела
и есть мышь (Δ 0), поэтому `entity_at` попадает; промах ощущается глазами: игрок целится остриём/топором, а «кликает» пустым углом
на 15–30 px выше. Один соседний эффект: у леса `entity_at` ловит соседнее дерево (спрайты перекрываются) — курсор верный.

## 🛠 Рецепт

1. **Вертикально перевернуть стрелку 0 A.D. при сборке** (`tools/build_ui_assets.py`: для `arrow-default-down` — `ImageOps.flip`,
   прицел остаётся (1,1); остриё окажется в (0,0)). Δ 30 → 0. Цена: 1 строка + пересборка. Это снимает «перевёрнуто» сразу.
2. **DE-стиль для действий: один предмет без стрелки**, рабочий конец в верхнем-левом углу, прицел (1,1):
   `ui_icon_art.cursor()` → без `alpha_composite(arrow)`, предмет `paste_fit` в (0,0)–(1,1) с поворотом так, чтобы лезвие/боёк/остриё были ↖
   (топор 0 A.D. `wood_axe`, кирка `mining_pickax`, серп, копьё, корзина, ладони — уже вырезаны). Для сдачи ресурса — корзина по ресурсу
   (еда/дерево/золото/камень), для лечения — только ладони. Δ 15 → 0, вид как в DE. Цена: ~40 строк в `ui_icon_art.py`, регенерация 9 `de_*.png`.
3. **Меч**: не уменьшать 64→32 весь холст, а вырезать рамку рисунка (23×23) и растянуть до ~30 px, прицел (0,0). Цена: 5 строк в `Cursors.get`
   (crop по bbox перед `smoothscale`) или пересобрать файл 32×32 в `build_ui_assets`.
4. **Retina**: SDL2 не принимает 2× представление. Варианты: (а) оставить (курсор 32 пт как у системных, мыло только на Retina);
   (б) программный курсор — `pygame.mouse.set_visible(False)`, рисовать картинку 32 px в конце `draw()` по `get_pos()` минус прицел:
   курсор тогда в той же пиксельной сетке, что игра (тоже ×2), и все прицелы под нашим контролем; цена — 1 кадр задержки, ~25 строк
   в `hud.update_cursor`/`draw`, скрывать при выходе мыши из окна. (в) при переходе на SDL3/pygame-ce 3: `SDL_AddSurfaceAlternateImage` с 64-px копией.
   Размер относительно вида: 32/800 против 32/1080 в DE — уменьшить курсор до ~26 px или оставить (⚠️).
5. **Состояния**: `cursor_kind` — сигнал → `flare` (рог), режимы приказа → свои значки (`patrol` сапог, `guard`, `follow`, `amove`, `aground`),
   точка сбора → `rally` при выбранном здании с флагом (DE), торговля → `trade`, посадка → `board`/`unload`; гарнизон жителей в центр без Alt,
   если ноша пуста (DE). Файлы: 0 A.D. `action-patrol`, `action-guard`, `action-setup-trade-route`, `action-unload`, `cursor-flare` есть в
   `assets/0ad_raw/public/art/textures/cursors/` (все прицел 1 1) — добавить в `build_ui_assets` и `CURSOR_FILES`. Цена: ~30 строк.
6. **Проверка** после правок: `cursor_static.py` (остриё = прицел для каждого файла, допуск 1 px) + `cursor_hover_probe.py` (27/27) +
   `cursor_real_window.py` с разрешением на снимок экрана.

Порядок по отдаче: 1 → 2 → 3 → 5 → 4.
