21–30 сентября 2022 года. Ты — Артём, 27 лет, программист, один в машине по дороге из Москвы в Тбилиси. Впереди 25 км очереди по Дарьяльскому ущелью. Политики и злодеев в игре нет. Есть очередь, люди в ней и десять дней, чтобы пройти.

## 🎮 Управление

| | Клавиатура и мышь | Телефон |
|---|---|---|
| Осмотреться | клик, затем мышь (`Esc` — отпустить) | тянуть справа |
| Идти · бежать | `W` `A` `S` `D` · `Shift` | левый стик · кнопка 🚶 |
| Действие с тем, кто под прицелом | `E` | тап · кнопка ✋ |
| Выйти из машины / сесть | `F` | кнопка 🚗 |
| Фонарик · сон · звук | `L` · `Z` · `N` | кнопка ⚡ · «Сон» |
| Сказать своё 🎙 | держать `V` | держать 🎙 |
| Карта ⇄ от первого лица | `M` | «Карта» |
| Пауза · скорость ×1 ×4 ×16 | `Пробел` · `1`–`4` | кнопки сверху |
| Телефон · рюкзак · к своей машине | `P` · `B` · `C` | кнопки снизу |
| Карта: двигать · масштаб | тянуть · колесо, `+` `−` | тянуть · щипок |
| Закрыть · заглушить голос | `Esc` | ✕ |

На ×1 игровой час идёт примерно минуту.

## 🔊 Голоса (по желанию)

По умолчанию выключено: без ключа игра целиком текстовая.

| | |
|---|---|
| 🔑 **Включить** | ключ с [platform.openai.com/api-keys](https://platform.openai.com/api-keys) → вставить в карточку на старте или ⚙ → «Голос + текст» → «Проверить» |
| 🗣 **Голоса** | у каждого человека с именем свой голос; безымянная толпа звучит стабильно, со своим настроением и акцентом; ⚙ → «Голоса» — послушать |
| 🎙 **Разговор** | держи `V`, глядя на человека, или пиши. Ответ зависит от мира: цены, слухи, день, твои деньги, прошлые разговоры. Меняет доверие, цены и помощь — всегда после твоего «да» |
| 💰 **Цена** | платно, по тарифам OpenAI; каждая озвученная фраза оплачивается один раз и кэшируется в браузере; реплика в разговоре ≈ 1–2 тыс. токенов + несколько секунд речи |
| 🔒 **Приватность** | ключ хранится только в этом браузере (localStorage); запросы идут напрямую в OpenAI; в сохранении — только текст последних реплик; «Удалить ключ» — в ⚙ |

Микрофону нужен https, localhost или `file://` в браузерах на Chromium; где его нет, кнопка 🎙 скрыта, а текстом говорить можно.

## 🛠 Запуск

Двойной щелчок по `index.html`. Сервер, сборка и библиотеки не нужны.

Работает и с любого статического сервера:

```bash
cd lars/tests && npm install      # один раз, для тестов
node serve.js                     # http://127.0.0.1:8080/
```

Тесты (Node + Playwright):

| | |
|---|---|
| `node sim-queue.js` | очередь по дням против цифр исследования, ожидание, скорость шага |
| `node smoke.js` | без ошибок с сервера и с `file://`; ходьба, меню, машина, карта, лавка, телефон, сохранение; голоса и разговор с подменённым OpenAI |
| `node perf.js` | замедленный процессор: ноутбук и телефон, пешком, в машине, ночью, карта |
| `node shots.js` | снимки в PNG в `docs/screenshots/` (`ANGLE=swiftshader` — программный GPU) |

Картинки в README — JPG-копии: `sips -s format jpeg -s formatOptions 82 in.png --out out.jpg`.

## 🧱 Устройство

Обычные `<script>`, зарегистрированные в одном реестре `L` (ES-модули не грузятся с `file://`), один цикл кадра, симуляция с фиксированным шагом и сидом, отдельно от отрисовки. Движок не знает конкретных историй: весь контент — в данных.

| Папка | Что делает |
|---|---|
| `js/core.js` | RNG с сидом, шина событий, часы и календарь, фиксированный шаг, сохранение |
| `js/sim/` | дорога, очередь, потребности и погода, экономика, слухи, режиссёр событий, язык условий и эффектов |
| `js/render/` | WebGL: ущелье по профилю маршрута, машины, люди, посёлки, КПП, огни, небо; игрок от первого лица; карта сверху на Canvas 2D; синтезированный звук; адаптивное качество |
| `js/ui/` | свои иконки, HUD, меню действий, карточки событий, телефон, рюкзак и лавка, итог, настройки, окно разговора |
| `js/audio/` · `js/ai/` | озвучка OpenAI с кэшем; живой разговор: подсказка из состояния мира, белый список последствий |
| `js/content/` | **данные**: календарь, маршрут, товары, люди, роль, слухи, события, действия, телефон, голоса — схема в шапке каждого файла |

Личные истории обезличены: имена убраны, оставлены возраст, занятие и ситуация. Персонажи игры собирательные, имена вымышлены. Разборы открытых чатов очереди содержат дословные цитаты реальных людей и хранятся закрыто.

## 🤍 О теме

В этой очереди стояли десятки тысяч человек, и у каждого своя история. Игра не пересказывает ни одну из них напрямую. В ней нет злодеев и нет чьей-то стороны: у людей, фактов и чувств всегда есть и хорошее, и плохое. Если ты был там — надеемся, это похоже на правду.
