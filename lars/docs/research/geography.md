# География, маршрут, облик — «Ларс»

Исследование для зон, карты маршрута, очереди сверху и 3D вблизи.
Время мира: 21–30 сентября 2022.

**Как получены числа.**
- Километраж — по маршруту OSRM (данные OpenStreetMap) от центра Владикавказа (пл. Свободы, 43.0247, 44.6819) до центра Тбилиси; точки OSM спроецированы на линию дороги. Погрешность ±0,3 км.
- Высоты — цифровая модель рельефа (Copernicus DEM 90 м через open-meteo) по оси дороги + теги `ele` из OSM. В узком ущелье DEM «цепляет» склоны: ±30–60 м.
- Погода — реанализ ERA5 (archive-api.open-meteo.com) за 20.09–01.10.2022. Это модель по сетке ~10 км, не станция: в горах даёт тренд и «какой был день», а не точный градус.
- Всё, что помечено **(оценка)**, — вывод, не факт из источника.

Сырые данные (маршрут, профиль высот, точки) лежат в scratchpad-сессии исследования; ниже — уже сведённые таблицы.

## 2. Планы КПП (ASCII, по геометрии OSM, ±10 м)
